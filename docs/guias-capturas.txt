GUÍA PARA TOMAR LAS CAPTURAS DE PRUEBAS
Sistema de Gestión de Investigación
====================================================================

PREPARACIÓN (hacer una sola vez)
--------------------------------
1. Levanta la aplicación:

   cd "/home/sym/Documentos/Universidad/Quinto/Administracion de Base de Datos/Semana 15/Investigacion"
   ./gradlew bootRun

2. Espera el mensaje: Started InvestigacionApplication ...
3. Abre el navegador en: http://localhost:8080
4. Usa estos accesos según la prueba:

   admin_sistema   / Admin123!      -> Administrador
   secretaria      / secre1         -> Secretaría
   Secretaria2     / secre2         -> Secretaría
   coordinador     / Coord123!      -> Coordinador
   director_inv    / Direct123!     -> Director
   profesor        / Profe123!      -> Docente (María Fernanda Gavilanes Silva)
   estudiante      / Estudi123!     -> Estudiante (Kevin Alexander Chela Guamán)

5. Para guardar la imagen en Linux puedes usar:

   gnome-screenshot -f captura_01_login.png
   scrot captura_01_login.png
   import -window root captura_01_login.png

   En Windows: Win + Shift + S.  En macOS: Cmd + Shift + 4.

6. Recomendación: navegador al 100 % y capturar solo la ventana del navegador
   o el terminal, sin escritorio de por medio.

--------------------------------------------------------------------
CAPTURA 01 - Login y panel
--------------------------------------------------------------------
1. Abre http://localhost:8080 sin sesión iniciada.
2. Captura el formulario solo (usuario, contraseña y botón Entrar).
3. Ingresa con admin_sistema / Admin123!.
4. Captura el panel: barra lateral con "Administrador del sistema" y el
   encabezado "Inicio".
5. Guarda como: captura_01_login.png

--------------------------------------------------------------------
CAPTURA 02 - Control por roles (HTTP 403)
--------------------------------------------------------------------
1. Abre un terminal y ejecuta:

   curl -s -c /tmp/cprof.txt -H 'Content-Type: application/json' \
     -d '{"usuario":"profesor","password":"Profe123!"}' \
     http://localhost:8080/api/auth/login

   curl -i -b /tmp/cprof.txt http://localhost:8080/api/proyectos

2. El terminal debe mostrar HTTP/1.1 403 y el mensaje
   "El rol Profesor no tiene permiso para ejecutar esta operacion."
3. Captura el terminal con ambas líneas.
4. Guarda como: captura_02_roles.png

CAPTURA 04 - Reportes CM
--------------------------------------------------------------------

CAPTURA 05 - Registro de proyecto
--------------------------------------------------------------------
1. Entra con secretaria / secre1 (o Secretaria2 / secre2).
2. Haz clic en "Operaciones".
3. Expande "Registrar proyecto".
4. Llena:
   Nombre: Proyecto de captura
   Acrónimo: CAPTURA1   (si ya existe, usa CAPTURA2)
   Presupuesto: 8000
   Programa: Programa de pruebas
   Descripción: Proyecto creado para evidencia
   Inicio: 2026-12-01
   Fin: 2027-06-30
   Resolución: RCU-CAP-001
5. Haz clic en "Registrar proyecto".
6. Captura el mensaje verde de éxito.
7. Guarda como: captura_05_proyecto.png

--------------------------------------------------------------------
CAPTURA 06 - Prórroga
--------------------------------------------------------------------
1. Con la misma secretaria, en "Operaciones" expande "Control de prórroga".
2. Selecciona el proyecto CAPTURA1.
3. Escribe como nueva fecha: 2027-09-15.
4. Haz clic en "Registrar prórroga".
5. Captura el mensaje de éxito.
6. Opcional: entra con secretaria, abre "Proyectos", haz clic en el proyecto
   CAPTURA1 y captura el detalle con la columna "Prórroga" llena.
7. Guarda como: captura_06_prorroga.png

CAPTURA 14 - Validación y rollback
--------------------------------------------------------------------
1. Entra con secretaria / secre1.
2. En "Operaciones" expande "Registrar proyecto".
3. Llena los datos pero en Presupuesto escribe: -1.
4. Haz clic en "Registrar proyecto".
5. Captura el mensaje rojo: "El presupuesto no puede ser negativo."
6. Para el rollback, repite con:
   Inicio: 2027-12-01
   Fin:    2026-06-30
   y captura el mensaje "Transaccion revertida".
7. Guarda como: captura_14_error.png

--------------------------------------------------------------------
CAPTURA 15 - Compilación
--------------------------------------------------------------------
1. Abre un terminal en la carpeta Investigacion.
2. Ejecuta:

   ./gradlew build
   node --check src/main/resources/static/app.js

3. Captura el terminal con "BUILD SUCCESSFUL" y sin errores de JS.
4. Guarda como: captura_15_build.png
